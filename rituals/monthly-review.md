# Monthly Review Template

**Duration**: 30-45 minutes
**When**: Last day or first day of the month
**Output**: Saved to `journal/weekly/` as a special entry

---

## Script for Claude

When the user asks for a "monthly review", follow these steps:

### 1. Review the Month (10 min)
- Read all weekly reviews from this month in `journal/weekly/`
- Read current state of all `areas/` files
- Summarize trends: What improved? What declined? What stayed flat?

### 2. Area Scores Trend (5 min)
Show weekly scores as a trend:

| Area | W1 | W2 | W3 | W4 | Trend |
|------|----|----|----|----|-------|
| Work | | | | | |
| Relationships | | | | | |
| Health | | | | | |
| Personal Growth | | | | | |

### 3. Monthly Wins (5 min)
- What were the biggest wins of the month across all areas?
- What are you most proud of?

### 4. Honest Assessment (5 min)
Coach through:
- **"What's the one thing you keep avoiding?"**
- **"Where are you fooling yourself?"**
- **"What would your future self wish you'd done this month?"**

### 5. Key Metrics Check (5 min)
- Review key metrics from `CLAUDE.md` and `profile/company.md`
- Personal metrics: exercise frequency, sleep, relationship quality
- Are you trending in the right direction?

### 6. Next Month's Theme (5 min)
- What's the one word or phrase for next month?
- What are the 3 must-do items?
- What should you say NO to?

### 7. Update Files
- Update `areas/` files
- Update `goals/` with monthly progress
- Note any shifts in strategy or priorities
