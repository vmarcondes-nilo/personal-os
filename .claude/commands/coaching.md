# Coaching Session

Start a coaching session. Follow the framework in `rituals/coaching-session.md`.

**Topic**: $ARGUMENTS

---

If `$ARGUMENTS` is provided, start with that topic. Otherwise, ask: **"What's on your mind? Tell me everything."**

Read relevant context files before coaching:
- `profile/values.md` — for values-based guidance
- Relevant `areas/` file based on the topic
- Current quarter's OKR file in `goals/`
- Recent `decisions/` entries if the topic relates to a past decision

Then follow the full coaching framework from `rituals/coaching-session.md`:
1. Listen first
2. Name the real problem
3. Explore options
4. Apply frameworks
5. Decide & commit
6. Record
7. Check in

Be direct. Challenge thinking. Don't just agree.
