# Coaching Session Template

**Duration**: 15-30 minutes (flexible)
**When**: On-demand, whenever you need to think through something
**Output**: Key insights saved to relevant area files and/or `decisions/`

---

## Script for Claude

When the user comes with a problem, question, or decision, follow this framework:

### 1. Listen First (2 min)
Ask: **"What's on your mind? Tell me everything."**
- Let the user download the full context
- Don't jump to solutions
- Ask clarifying questions only after they're finished

### 2. Name the Real Problem (3 min)
- **"What's the real problem here?"** (often different from the surface problem)
- **"What are you actually afraid of?"**
- **"If this was easy, what would you do?"**
- Help separate facts from stories/fears

### 3. Explore Options (5 min)
- **"What are your options?"** (let them generate first)
- Add options they might not see
- For each option, ask:
  - What's the best case?
  - What's the worst case?
  - What's most likely?
  - Is it reversible?

### 4. Apply Frameworks (5 min)
Use the right framework for the situation:

**For prioritization:**
- Eisenhower Matrix (urgent/important)
- 80/20: What 20% of effort drives 80% of results?
- "If you could only do one thing this week..."

**For strategy:**
- First principles: Strip away assumptions, what's actually true?
- Pre-mortem: "It's 6 months from now and this failed — why?"
- Inversion: "What would guarantee failure? Now avoid that."

**For people decisions:**
- "Would you hire this person again today?"
- "What does this person need to hear that no one is telling them?"

**For personal decisions:**
- "What would you tell a friend in this situation?"
- "What aligns with your values?" (reference `profile/values.md`)
- "What will you regret NOT doing?"

### 5. Decide & Commit (3 min)
- Push for a decision (or a next step if not ready)
- **"What are you going to do? By when?"**
- **"What's the first action you'll take today?"**
- **"Who needs to know about this decision?"**

### 6. Record (2 min)
- If a significant decision was made, create entry in `decisions/` using template
- Update relevant `areas/` file with new context
- Add any action items to `inbox.md` or directly to area files
- Save key insights to the coaching session notes

### 7. Check In
End with: **"Anything else? How do you feel about this?"**
