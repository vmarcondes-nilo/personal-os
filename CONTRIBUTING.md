# Contributing

Thanks for your interest in improving personal-os! This is an open-source project and contributions are welcome.

## How to Contribute

### Reporting Issues

- Open an [issue](https://github.com/vmarcondes-nilo/personal-os/issues) describing the bug or suggestion
- Include steps to reproduce if it's a bug
- Screenshots of your terminal output are helpful

### Submitting Changes

1. Fork the repo
2. Create a branch (`git checkout -b my-improvement`)
3. Make your changes
4. Test by running the affected slash commands in Claude Code
5. Commit with a clear message
6. Open a Pull Request

### What's Most Helpful

- **Better templates** — improvements to ritual templates, area files, or slash commands
- **New slash commands** — useful workflows that others would benefit from (add to `.claude/commands/`)
- **Documentation** — clearer setup instructions, tips, translations
- **Starter kit improvements** — making the non-technical setup smoother
- **Bug fixes** — if a command doesn't work as described, fix it

### Guidelines

- Keep files concise — this system should be easy to scan
- Don't add dependencies — the whole point is plain markdown + Claude Code
- Use placeholders (`[Your name]`, `[Your company]`, etc.) in templates — never hardcode personal data
- Test your changes by actually running them in Claude Code before submitting

### Translations

The README and starter kit currently support English and Portuguese. Translations to other languages are very welcome — add them as new files (e.g., `starter/SETUP-es.md` for Spanish).
